## Question: How are graceful degradation and service workers related?
Graceful degradation and service workers are related because service workers help web applications continue functioning even when network conditions are poor or the user is offline. Graceful degradation is the idea that an application should still provide a usable experience when advanced features fail or become unavailable. Service workers support this by caching important files and network responses so that users can still access core content and functionality even without a proper internet connection, allowing the app to fail gracefully and reamian minimum functionality instead of completely breaking.
